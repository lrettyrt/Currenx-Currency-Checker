# 💱 Currenx — Currency & Crypto Tracker

Веб-приложение для отслеживания курсов фиатных валют и криптовалют в реальном времени.

## Возможности

- **Темный UI** — современный дизайн на Tailwind CSS
- **Чекбоксы валют** — включите/выключите нужные валюты (USD, EUR, BTC, ETH, SOL и другие)
- **Поиск** — быстрый поиск по тикерам и названиям
- **Конвертер** — мгновенная конвертация между фиатом и криптой
- **PWA** — установите как десктопное приложение
- **Автообновление** — курсы обновляются каждые 60 секунд

## Структура проекта

| Файл | Описание |
|------|----------|
| `index.html` | Разметка приложения |
| `style.css` | Стили (Tailwind CDN + кастомные) |
| `app.js` | Логика интерфейса, чекбоксы, поиск |
| `api.js` | Запросы к CoinGecko и ExchangeRate-API |
| `manifest.json` | PWA манифест для установки на ПК |
| `service-worker.js` | Кэширование и офлайн-поддержка |
| `fullfile_0.0.0.1.html` | Монолитная версия (всё в одном файле) |
| `currenx_currency.updates.cx.txt` | Лог обновлений |

## Запуск

### Вариант 1: Через сервер
```bash
# Любой HTTP-сервер, например:
npx serve .
# или
python3 -m http.server 8000
```
Откройте `http://localhost:8000`

### Вариант 2: Монолитный файл
Откройте `fullfile_0.0.0.1.html` двойным кликом в браузере.

## Установка как PWA

1. Откройте приложение в Chrome
2. Нажмите иконку установки в адресной строке (или меню → «Установить приложение»)
3. Приложение появится на рабочем столе

## API

- **Криптовалюты**: [CoinGecko API](https://www.coingecko.com/api/documentation) (бесплатно, без ключа)
- **Фиатные валюты**: [ExchangeRate-API](https://open.er-api.com/) (бесплатно, без ключа)

## Поддерживаемые валюты

**Фиат:** USD, EUR, GBP, JPY, RUB, CNY, CHF, CAD, AUD, TRY

**Крипто:** BTC, ETH, SOL, BNB, XRP, ADA, DOGE, DOT, MATIC, LTC, AVAX, LINK, UNI, ATOM, TON
